# CMPC Security Projects

Portofoliu Astro complet static, construit pentru Cloudflare Pages și centrat exclusiv pe proiecte.

## Conține

- homepage project-first;
- arhivă de proiecte și pagini statice individuale;
- Project Lab cu date demonstrative;
- formular de contact prin FormSubmit;
- pagină Privacy și 404;
- responsive design, SEO, sitemap și headere de securitate.

## Comenzi

```bash
npm install
npm run dev
npm run check
npm run build
```

Instrucțiunile complete sunt în `DEPLOY-CLOUDFLARE.md`.
